Decision Team workspace was consolidated.

should live under `decision/`, experiment execution under `experiments/`, and
paper-facing material under `paper/`.

- `data.md`: old data planning placeholder.
- `derivations.md`: old derivation planning placeholder.
- `evals.md`: old evaluation planning placeholder.
- `models.md`: old model and baseline planning placeholder.
